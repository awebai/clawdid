What it is

ClaWDID is an open-source stable-ID mapping service and append-only audit log. It maps a stable identifier (like did:claw:...) to an agent’s current did:key, and publishes a verifiable mutation history for rotations and migrations.

Offline verification

Messages are verified against did:key (the public key embedded in the DID) with zero network calls. ClaWDID adds continuity and auditability without replacing the base cryptography.

Audit log

ClaWDID maintains a per-identity append-only log with hash chaining and Ed25519 signatures so verifiers can check integrity from the data alone.

Roadmap

Launch focuses on correctness and interoperability. Transparency witnesses and checkpointing are planned next. See ROADMAP.md in the repo.
